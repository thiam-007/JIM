# Images JIM 2026 — dossier de dépôt

Déposez les fichiers image dans ce dossier. L'application les charge automatiquement.

| Fichier attendu       | Usage                                      | Taille recommandée |
|-----------------------|--------------------------------------------|--------------------|
| `logo.png`            | Logo réel MVG dans le header               | 120×120 px min, fond transparent (.png) |
| `banner.jpg`          | Bannière hero en haut de la page d'accueil | 1400×500 px min    |
| `background.jpg`      | Texture/fond de l'application              | 1920×1080 px min   |
| `side-photo.jpg`      | Photo latérale sur la page d'accueil       | 600×800 px min     |
| `favicon.png`         | Icône de l'onglet navigateur               | 64×64 px           |

> Si un fichier est absent, l'application affiche un rendu de secours (texte, dégradé couleur).
