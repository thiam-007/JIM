## 📐 Recommandations

- **Format** : JPG ou JPEG recommandé (PNG accepté)
- **Dimensions** : minimum **640 × 480 px**, idéal **1280 × 960 px**
- **Orientation** : Paysage (horizontale) de préférence
- **Poids** : inférieur à **500 Ko** par image pour de bonnes performances
- **Sujet** : Photo ou capture d'écran de l'objet / du site en question

## ⚙️ Comment ajouter les photos

1. Prenez vos photos ou captures depuis Sketchfab / le Musée National
2. Renommez chaque fichier selon le tableau ci-dessus
3. Glissez-les dans ce dossier `galerie-3d/`
4. Le carrousel sur la page d'accueil les affichera automatiquement

> **Note :** Tant qu'un fichier n'est pas encore présent, le carrousel utilise
> les images de substitution existantes (`side-photo.jpeg`, `stand-mvg.jpeg`, etc.)
